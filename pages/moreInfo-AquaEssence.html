Aqua Essence

Aqua Essence is a real-client scheduling and matching project built for swim instruction operations. The system combines a FastAPI service layer in Python with C++17 matching logic to assign about 1,800 swimmers per week to instructors while respecting real-world constraints such as availability, capacity, skill level, and operational rules.

Key Features And Functionalities

  • Constraint-Based Matching: Designed matching logic to place swimmers with instructors under competing scheduling, capacity, and skill constraints.
  • FastAPI Service Layer: Built Python API workflows to coordinate matching requests, inputs, and responses through a structured service boundary.
  • Offline Desktop Host: Built a C++ desktop host/server for offline matching so the browser-based UI could keep operating through local HTTP/JSON endpoints.
  • Local API Surface: Exposed 20+ local HTTP/JSON endpoints to power the UI, manage matching data, and keep the system usable without relying on a cloud backend.
  • Client-Focused Delivery: Prioritized reliability, clear outputs, and workflow fit so the system could support a real scheduling process instead of only demonstrating a technical prototype.
