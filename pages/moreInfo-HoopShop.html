HoopShop

Built an online basketball store where users can search and filter products, view recommendations, and manage their shopping cart. I also organized the code so it is easier to maintain and work on as a team.

Main Features

  • Finding Products: Added a product roulette, filters, and a "you might also like" section to help users find more products.
  • Cart And Checkout: Built a cart that shows each item and price, lets users change what is in the cart, applies discounts, and updates the checkout total.
  • Interactive Pages: Used JavaScript and jQuery for product search, a mini-cart that works across the site, and grid or list views for products.
  • Accessibility And Performance: Followed web accessibility and performance practices so the store is easier to use and loads well for more people.
