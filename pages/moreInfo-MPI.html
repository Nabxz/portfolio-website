MPI Alarm Monitor

A parallel C application using MPI to distribute a fixed set of alarms across worker ranks, compute a severity score per alarm in parallel, and aggregate totals on the manager (rank 0). Demonstrates block data decomposition, point-to-point messaging with MPI_Send/MPI_Recv, and deterministic aggregation on the root process. Built to practice distributed design, workload partitioning, and correctness under concurrency.

Key Features And Functionalities

  • Parallel Workload Partitioning: Evenly divides alarms among ranks using block decomposition to maximize utilization and minimize stragglers.
  • Message Passing (P2P): Uses MPI_Send/MPI_Recv for explicit data movement and result collection; rank 0 orchestrates distribution and gathers partial sums.
  • Rank/Size Awareness: Robust handling of edge cases (e.g., fewer alarms than ranks) and non-uniform partitions.
  • Aggregation & Reduction: Manager process computes global totals and severity distribution; logs per-rank contributions for verification and debugging.
  • Deterministic Runs: Optional seeded RNG for reproducible severity generation during testing.
  • Portable Build: Standard mpicc/mpirun workflow; runs on local multi-core or cluster environments with OpenMPI/MPICH.
