Electric Automotive

Built a full-stack website for people interested in electric cars. Users can view car promotions and articles, find dealerships, and manage their account on both desktop and mobile devices.

Main Features

  • Search And Filters: Added filters and live search for car listings and blog posts using jQuery and AJAX, so results update while the user is searching.
  • Dealership Map And Forms: Used Leaflet.js to build a dealership map with location support and forms that change based on the user's dealership question.
  • User Accounts: Built sign-in, sign-up, and profile editing with AJAX so users can manage their account without reloading the page.
  • APIs And Live Data: Connected custom APIs and API Ninjas with AJAX to load car data and update the page without a full reload.
