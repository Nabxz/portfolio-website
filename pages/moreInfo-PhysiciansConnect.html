PhysiciansConnect

Built a healthcare desktop app with Java 21, Swing, SQLite, JUnit 5, and Gradle. It includes different storage options, profile management, and tests for the main features.

Main Features

  • Storage Options: Built SQLite and in-memory storage with Java interfaces so the app can switch between them without changing the main code.
  • Profile Management: Added profiles for physicians and receptionists with Swing and SQLite, including photo uploads and resizing.
  • Tests: Wrote JUnit 5 tests with in-memory SQLite to check appointments, prescriptions, referrals, and messages.
