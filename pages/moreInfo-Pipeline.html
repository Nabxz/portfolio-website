Pipeline CPU Simulator (with Branch Prediction)

Built a C++ simulator for a CPU pipeline with six stages: IF, ID, EA, OF, EX, and WB. It finds hazards, forwards data, adds stalls when needed, and compares static branch prediction with no prediction. It also catches illegal instructions and addresses, stops infinite loops, and reports branch accuracy, memory, and register values. My instructor provided the assembler, and I built the simulator and pipeline logic.

Main Features

  • Pipeline Stages: Uses IF for fetch, ID for decode, EA for the address, OF for operands, EX to run the instruction, and WB to write the result, with a latch for each stage.
  • Handling Hazards: Finds RAW hazards, adds stalls only when needed, and forwards data to reduce waiting.
  • Branch Prediction: Treats backward branches as taken, compares the results with no prediction, and reports the accuracy and cost of wrong predictions.
  • Errors And Infinite Loops: Catches illegal opcodes and addresses, and uses a branch limit to stop infinite loops.
  • Debug Information: Shows memory with ASCII text, register values, and the state of each pipeline stage.
  • Build And Run: Use make to build it, then run it with ./pipeline_sim program.code program.data.
