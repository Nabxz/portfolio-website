Pipeline CPU Simulator (with Branch Prediction)

A C++ simulator of a pipelined CPU implementing six modeled stages (IF, ID, EA, OF, EX, WB) with hazard detection, operand forwarding, and stall insertion. Includes static branch prediction (code-pattern: backward branches as taken) vs. no prediction, plus robust exception handling for illegal opcodes/addresses and infinite loop detection. Produces branch prediction accuracy reports and memory/register diagnostics. (Assembler provided by instructor; I implemented the simulator & pipeline logic.)

Key Features And Functionalities

  • Pipeline Stages: IF (fetch), ID (decode), EA (effective address), OF (operand fetch), EX (execute), WB (write-back) with per-stage latches.
  • Hazard Handling: RAW detection, targeted stalls, and forwarding to reduce bubbles.
  • Branch Prediction: Static code-pattern predictor (backward=taken) vs. no prediction; reports accuracy and penalties.
  • Exceptions & Robustness: Illegal opcode/address traps and infinite loop guard via branch limit.
  • Diagnostics: Memory dumps with ASCII translation, register file snapshots, and pipeline state tracing.
  • Build & Run: make to build; run with ./pipeline_sim program.code program.data.
